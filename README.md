# низкоорбитальные спутники

48 спутников, по этапно выводтяся на орбиту < 500км

обеспечение широкополосных связей для наземных пользователей 

интерейфес, модель(наиболее богатая на конфигурацию)

1) отказ спутника при сохранения связи
2) выбор оптимальной мащрутизации


менять фазы выоходв нельзя

Заметьте, что добавление второго шлюза подняло C72 с 98,89 % до 100 % — это дешевле, чем добавлять спутники. Отраслевые эксперты такой вывод любят: «целевая доступность достигается либо полным развёртыванием группировки, либо вторым шлюзом на востоке». Это прямое попадание в критерий «обоснованность рекомендаций» (10 баллов), и посчитать это у вас займёт пять минут, раз код уже поддерживает несколько шлюзов.
